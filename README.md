# Markov2026
This is my repo for APPM 4560 (Markov Processes) at CU Boulder.

## What is here?
Runnable code is stored here. Other files related to assignments or environment are not stored here.

Stored here:
- Files that generate outputs related to assignment questions
- Quick start script to run files quickly

Not stored here:
- Write ups for assignments
- Generated plots

## How to run files
Simply run:
```bash
python run.py
```
or:
```bash
python3 run.py
```
Depending on your setup.

The script includes a build-in GUI that allows you to select which python file to run easily. 

This script is designed to work on across Macos, Linux, and Windows.
